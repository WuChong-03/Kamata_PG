# 函数的重载与函数模板

## 1. 函数的重载（オーバーロード）

“`函数名相同`，但`参数组合`不同” 的写法 就叫做 **函数重载**。

函数名和参数类型、参数数量的组合，也叫做函数的 **签名（Signature）**。

调用函数时，C++ 会根据传入参数对应的签名，自动选择合适的函数。

```cpp
int calc(int a, int b) {
    return a + b;
}

float calc(float d, float e) {
    return d + e + 10;
}

int x = 114;
int y = 514;
float l = 3.64f;
float m = 3.64f;

printf("%d\n", calc(x, y)); //调用int的calc
printf("%f\n", calc(l, m)); //调用浮点数的calc
```

## 2. 函数模板

函数模板可以理解为：**让一个函数可以适用于多种类型**。

如果多个函数的处理内容几乎一样，只是参数类型不同，就可以使用函数模板来减少重复代码。

例如原本可能要分别写：

```cpp
int add(int a, int b) {
    return a + b;
}

float add(float a, float b) {
    return a + b;
}
```

使用函数模板后，可以写成：

```cpp
template <typename Type>
Type add(Type a, Type b) {
    return static_cast<Type>(a + b);
}
```

这里的 `Type` 是一个临时的类型名字，之后可以被替换成 `int`、`float` 等实际类型。

也就是说：

```cpp
add<int>(114, 514);
```

调用时，`Type` 会被当作 `int` 使用。

```cpp
add<float>(11.4f, 51.4f);
```

调用时，`Type` 会被当作 `float` 使用。

完整示例：

```cpp
#include <stdio.h>

template <typename Type>
Type add(Type a, Type b) {
    return static_cast<Type>(a + b);
}

int main() {
    printf("%d\n", add<int>(114, 514));
    printf("%f\n", add<float>(11.4f, 51.4f));

    return 0;
}
```

---

## 3. 函数模板的声明与定义

函数模板的基本写法如下：

```cpp
template <typename Type>
Type add(Type a, Type b) {
    return static_cast<Type>(a + b);
}
```

这段代码可以分成三部分理解。

首先：

```cpp
template <typename Type>
```

表示声明一个模板类型 `Type`。  
这个 `Type` 之后会被实际类型替换，比如 `int`、`float` 等。

然后：

```cpp
Type add(Type a, Type b)
```

表示函数的返回值类型、参数类型都使用 `Type`。

最后：

```cpp
return static_cast<Type>(a + b);
```

因为返回值类型会根据调用时指定的类型变化，所以这里使用 `static_cast<Type>` 进行明确的类型转换，让返回值类型保持一致。

---

## 4. 常见写法

很多情况下，模板类型名会简写成 `T`。

下面两种写法意思相同：

```cpp
template <typename T>
T add(T a, T b) {
    return static_cast<T>(a + b);
}
```

```cpp
template <typename Type>
Type add(Type a, Type b) {
    return static_cast<Type>(a + b);
}
```

`T` 只是 `Type` 的简写，并没有特殊含义。  
但是对于初学者来说，`T` 看起来可能不太直观，所以刚开始可以先写成 `Type`，这样更容易理解。等习惯以后，再看书或网上资料里的 `T` 写法就不会觉得奇怪。

## 5. 函数模板的使用

函数模板可以通过下面的形式调用：

```cpp
函数名<类型>(参数);
```

例如：

```cpp
int main() {
    printf("%d\n", add<int>(114, 514));
    printf("%f\n", add<float>(11.4f, 51.4f));

    return 0;
}
```

这里：

```cpp
add<int>(114, 514)
```

表示把模板中的 `Type` 当作 `int` 使用。

```cpp
add<float>(11.4f, 51.4f)
```

表示把模板中的 `Type` 当作 `float` 使用。

简单来说，函数模板就是提前写好一套通用逻辑，调用时再指定具体类型。

---

## 6. 多个模板类型

如果函数中需要使用多个不同的类型，可以在模板声明中写多个类型名，并用逗号分隔。

例如：

```cpp
template <typename T1, typename T2>
T1 add(T1 a, T2 b) {
    return a + b;
}
```

这里有两个模板类型：

```cpp
T1
T2
```

`T1` 用来表示第一个参数和返回值的类型，`T2` 用来表示第二个参数的类型。

使用时也需要用逗号指定多个类型：

```cpp
add<int, float>(114, 51.4f);
```

完整示例：

```cpp
#include <stdio.h>

template <typename T1, typename T2>
T1 add(T1 a, T2 b) {
    return a + b;
}

int main(void) {
    printf("%d\n", add<int, float>(114, 51.4f));

    return 0;
}
```

因为这个函数的返回值类型是 `T1`，而这里指定的 `T1` 是 `int`，所以结果会以 `int` 类型返回。

```cpp
114 + 51.4f
```

计算结果本来是：

```cpp
165.4
```

但返回值是 `int`，小数部分会被舍去，所以最终显示：

```cpp
165
```

## 7. 模板的特殊化

函数模板可以处理很多类型，但有时我们希望某个类型使用特殊处理。  
这种情况可以使用 **模板的特殊化**。

例如，普通情况下 `add` 函数进行加法：

```cpp
template <typename T>
T add(T a, T b) {
    return a + b;
}
```

但是如果希望 `float` 类型调用时执行减法，就可以写一个专门针对 `float` 的版本：

```cpp
template <>
float add<float>(float a, float b) {
    return a - b;
}
```

完整示例：

```cpp
#include <stdio.h>

template <typename T>
T add(T a, T b) {
    return a + b;
}

template <>
float add<float>(float a, float b) {
    return a - b;
}

int main(void) {
    printf("%d\n", add<int>(114, 514));
    printf("%f\n", add<float>(11.4f, 51.4f));

    return 0;
}
```

执行结果中：

```cpp
add<int>(114, 514)
```

会使用普通函数模板，所以结果是：

```cpp
628
```

而：

```cpp
add<float>(11.4f, 51.4f)
```

会使用 `float` 专用版本，所以执行的是减法：

```cpp
11.4f - 51.4f
```

结果是：

```cpp
-40.0
```

这就是模板特殊化。  
它的作用是：**大部分类型使用通用模板，某些特殊类型使用专门写好的处理方式。**

---

## 8. 模板特殊化与函数重载的区别

模板特殊化和函数重载看起来有点像，但它们不是同一个东西。

模板特殊化是针对模板的某个类型写特殊版本，例如：

```cpp
template <typename T>
T add(T a, T b) {
    return a + b;
}

template <>
float add<float>(float a, float b) {
    return a - b;
}
```

这里的 `float` 版本是 `add` 函数模板的特殊处理。

函数重载则是直接定义一个同名但参数不同的普通函数，例如：

```cpp
float add(float a, float b) {
    return a * b;
}
```

它不是模板的一部分，而是一个普通函数。

## 9. 重载与模板可以组合使用

函数模板、模板特殊化和函数重载可以一起使用。

例如：

```cpp
#include <stdio.h>

template <typename T>
T add(T a, T b) {
    return a + b;
}

template <>
float add<float>(float a, float b) {
    return a - b;
}

float add(float a, float b) {
    return a * b;
}

int main(void) {
    printf("%d\n", add<int>(114, 514));
    printf("%f\n", add<float>(11.4f, 51.4f));
    printf("%f\n", add(11.4f, 51.4f));

    return 0;
}
```

上面的三个调用分别对应不同的函数。

```cpp
add<int>(114, 514)
```

使用普通函数模板：

```cpp
114 + 514 = 628
```

```cpp
add<float>(11.4f, 51.4f)
```

使用 `float` 的模板特殊化版本：

```cpp
11.4f - 51.4f = -40.0
```

```cpp
add(11.4f, 51.4f)
```

没有写 `<float>`，因此会优先匹配普通的函数重载版本：

```cpp
11.4f * 51.4f = 585.96
```

所以输出结果大致为：

```text
628
-40.000000
585.960000
```

---

## 10. 总结

函数重载、函数模板、模板特殊化的区别可以这样理解：

| 名称 | 作用 | 例子 |
|---|---|---|
| 函数重载 | 同名函数，根据参数不同调用不同版本 | `add(int, int)` / `add(float, float)` |
| 函数模板 | 写一个通用函数，让不同类型共用 | `template <typename T>` |
| 模板特殊化 | 针对某个类型写特殊处理 | `template <> float add<float>` |

简单记忆：

```text
函数重载：同名函数，不同参数。
函数模板：一个函数，适配多种类型。
模板特殊化：大部分用模板，某个类型单独处理。
```
