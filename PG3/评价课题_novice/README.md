# PG3 Simple Shooting

Noviceを使用した、シンプルな2Dシューティングゲームです。

## 操作方法

- `WASD`：プレイヤー移動
- `SPACE`：弾を発射
- `ENTER`：タイトル・リザルト画面の決定
- `ESC`：ゲーム終了

画面上から複数の敵が出現します。敵を撃つと100点を獲得し、敵は再び画面上から出現します。

## 制作で頑張ったところ

ステートパターンを使い、タイトル・ゲーム・リザルトを別々のクラスに分けました。
また、複数の弾と敵を`std::vector`で管理しました。

## 追加オリジナル仕様

複数の敵が異なる速度で上から出現し、画面外への移動または弾の命中後に繰り返し出現します。

## 必需要件

### ステートパターンによるシーン管理

`IScene`を共通インターフェースとして、次の3つのシーンクラスを作成しています。

- `TitleScene`
- `GameScene`
- `ResultScene`

`SceneManager`は現在のシーンを保持し、各シーンからの要求に応じて次のシーンへ切り替えます。
各クラスは`.h`と`.cpp`に分け、`main.cpp`にはゲームループだけを記述しています。

### UTF-8

`main.cpp`とこの説明ファイルはUTF-8で保存しています。

## 加点要素

### STLコンテナクラスの使用（+5）

`std::vector<Bullet>`を使って、画面内に存在する複数の弾を管理しています。

- 発射時：`push_back`で弾を追加
- 毎フレーム：範囲for文で全ての弾を移動
- 画面外・命中後：`erase`と`remove_if`で不要な弾を削除

固定長配列と異なり、必要な数だけ弾を保持できる点がメリットです。

敵も`std::vector<Enemy>`で管理し、複数の敵が上から下へ移動して繰り返し出現します。
