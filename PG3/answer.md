# 01_02 回答

再帰的な賃金体系のほうが儲かるのは、8時間働いたときです。

一般的な賃金体系は、時給1,072円なので、8時間働くと次の金額になります。

```text
1,072 * 8 = 8,576円
```

再帰的な賃金体系では、1時間目が100円で、次の1時間からは「前の1時間でもらった時給 * 2 - 50」になります。

```text
1時間目: 100円
2時間目: 150円
3時間目: 250円
4時間目: 450円
5時間目: 850円
6時間目: 1,650円
7時間目: 3,250円
8時間目: 6,450円
```

8時間分の合計は次のようになります。

```text
100 + 150 + 250 + 450 + 850 + 1,650 + 3,250 + 6,450 = 13,150円
```

7時間までは一般的な賃金体系のほうが高く、8時間働くと再帰的な賃金体系の合計が13,150円になり、一般的な賃金体系の8,576円を超えます。
