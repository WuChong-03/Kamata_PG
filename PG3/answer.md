# 課題回答

## 再帰的な賃金体系の比較

今回の課題では、一般的な賃金体系と再帰的な賃金体系を比較した。

一般的な賃金体系では、時給は常に `1,072円` である。

一方、再帰的な賃金体系では、最初の1時間の時給は `100円` であり、次の1時間からは次の計算式で時給が決まる。

```text
前の1時間でもらった時給 * 2 - 50
```

つまり、再帰的な賃金体系では、前の時間の時給を使って次の時間の時給を計算する。

## 計算結果

| 時間 | 一般的な賃金体系の合計 | 再帰的な賃金体系の時給 | 再帰的な賃金体系の合計 |
|---|---:|---:|---:|
| 1時間 | 1,072円 | 100円 | 100円 |
| 2時間 | 2,144円 | 150円 | 250円 |
| 3時間 | 3,216円 | 250円 | 500円 |
| 4時間 | 4,288円 | 450円 | 950円 |
| 5時間 | 5,360円 | 850円 | 1,800円 |
| 6時間 | 6,432円 | 1,650円 | 3,450円 |
| 7時間 | 7,504円 | 3,250円 | 6,700円 |
| 8時間 | 8,576円 | 6,450円 | 13,150円 |

## 結果

7時間働いた場合、一般的な賃金体系は `7,504円`、再帰的な賃金体系は `6,700円` なので、まだ一般的な賃金体系のほうが多い。

しかし、8時間働いた場合、一般的な賃金体系は `8,576円`、再帰的な賃金体系は `13,150円` となる。

したがって、再帰的な賃金体系のほうが儲かるのは、**8時間働いたとき**である。

## 答え

再帰的な賃金体系のほうが儲かるのは、**8時間働いたとき**である。
